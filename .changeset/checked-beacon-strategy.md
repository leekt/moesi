Add `compileCheckedBeaconProxy` for the pinned checked beacon/proxy family. The compiler produces ordinary current manifests with deterministic CREATE2 creation, fixed constructor identity, exact EOA owner requirements, typed beacon/owner assertions and runtime-checked upgrade calldata. Constructor guards prevent initialization through an unexpected beacon implementation. Guarded upgrades require exact nonempty implementation code; unguarded upgrades revert. Generated bytecode is reproducible from OpenZeppelin Contracts 5.6.1 and solc 0.8.30, with source/hash/license provenance.

Changing the desired implementation preserves beacon/proxy addresses. Initializer semantics and storage-layout compatibility require explicit caller review; this does not support arbitrary existing proxies, UUPS, transparent proxies or upgrade-and-call migrations. No persisted schema changes or compatibility paths.
