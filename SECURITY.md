# Security

Please report vulnerabilities privately through GitHub's security advisory
flow for `leekt/moesi`. Do not open a public issue containing secrets, signing
material, approval artifacts, or an exploitable proof of concept.

Moesi verifies reviewed calls and deployment semantics. Execution providers
separately own authorization, signing, submission, and operation finality.
OAAth additionally owns smart-account permissions, credentials, grants, and
operation identity. No provider evidence is accepted as a substitute for
Moesi's semantic convergence evidence.
